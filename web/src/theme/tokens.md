# 使えるトークン一覧

第3部 §15 の指示により、DADS のプラグインが実際に提供する値を列挙した。
**以降はこの一覧の外を使わない。** hex と任意 px は書かない（第3部 §3.3）。

実物は `@digital-go-jp/tailwind-theme-plugin@1.0.1` から取得した。
仕様書に書かれたトークン名は参考値であり、こちらが正。

## 色

| 系統 | 使える段階 |
|---|---|
| `solid-gray` | 50 100 200 300 400 420 500 536 600 700 800 900 |
| `blue` | 50〜1200 |
| `red` | 50〜1200 |
| その他 | key, light-blue, cyan, green, lime, yellow, orange, magenta, purple |

**この画面で意味を持たせる色は3種類まで**（第3部 §5）。

| 役割 | 使う色 |
|---|---|
| 本文・数値 | `solid-gray-900` |
| 補助・ラベル | `solid-gray-600` |
| 罫線（細） | `solid-gray-300` |
| 罫線（太・合計） | `solid-gray-600` |
| 注意（要レビュー） | `red-800` |
| リンク・選択 | `blue-900` |

増減は**必ず記号（△）と併記**する。色だけで判別させない。

## タイポグラフィ

本文は `std-*` 系、見出しは `dsp-*` 系。読み方は `std-<px>{B|N}-<行間>`。
B は太字、N は通常。

| 用途 | クラス |
|---|---|
| 画面見出し | `text-std-28B-150` |
| セクション見出し | `text-std-20B-150` |
| 本文 | `text-std-16N-170` |
| 補助 | `text-std-14N-170`（無ければ `std-16N-170`） |
| 表の見出し | `text-std-16B-170` |

**独自の font-size を定義しない。**

## 書体

| 役割 | クラス |
|---|---|
| 本文・見出し・UI | `font-sans`（Noto Sans JP） |
| **金額・数量・ID・ハッシュ** | `font-num`（Noto Sans Mono） |

`font-num` はこの設計で唯一 DADS から踏み出した箇所。
理由は装飾ではなく機能で、金額の桁が1px でもズレると読み違えが起きるため。
**適用は数字・記号のみ**に限る。日本語本文には使わない。

## 余白

Tailwind の既定スケール（`0 0.5 1 1.5 2 3 4 6 8 12 16`）を使う。
`p-[13px]` のような任意の値は書かない。

## 角丸・影

| | |
|---|---|
| `borderRadius` | 4 6 8 12 16 24 32 full |
| `boxShadow` | 1〜8 |

**影は使わない。** DADS に定義があるのは浮遊要素（ドロワー・ダイアログ）向けで、
それ以外に使うと第3部 §2.1 の禁止事項に当たる。
角丸も原則使わない。区切りは罫線と余白で作る。

## ブレークポイント

DADS が提供するのは `desktop: 48em` と `desktop-admin: 62em` の2つ。
第3部 §6.1 は3段（〜767px / 768〜1023px / 1024px〜）を求めているので、
`desktop`（768px 相当）と `desktop-admin`（992px 相当）を使い、
1024px 以上は `desktop-admin` で代用する。

> **要確認**: 第3部 §6.1 のデスクトップ境界は 1024px だが、
> DADS の `desktop-admin` は 62em（992px）。厳密には一致しない。
> 独自のブレークポイントを足すのは §3.3 に反するため、DADS 側に寄せた。

## 使わないもの（第3部 §2.1）

カード / ドロップシャドウ / グラデーション / 絵文字 / 中央寄せのヒーロー /
KPI カードの横並び / 意味のないアニメーション / Inter・Poppins・Montserrat /
紫〜青のアクセント / 装飾目的のアイコン / 角丸の乱用
