# shiwake

証憑から複式簿記の仕訳を組み立て、根拠を辿れる形で保全するためのツールキットです。
プレーンテキスト（Beancount）で記帳し、集計は決定的に再現できます。

## 免責

このソフトウェアは会計・税務の記録作成を補助するものであり、
税務上の助言ではありません。

- 出力される決算書・申告用の集計は**下書き**です。提出前に必ず自分で検証してください
- 税率・控除額・各種閾値は**同梱していません**。利用者が国税庁の情報を確認して設定します
- 電子帳簿保存法・インボイス制度への適合は**運用によって決まります**。
  このソフトウェアを使えば要件を満たす、というものではありません
- 第三者認証（JIIMA 認証等）を受けていません
- 無保証です（LICENSE 参照）

判断に迷う点は税理士または所轄の税務署にご確認ください。

## これは何か

- 領収書・明細・検針票などを構造化データに正規化し、そこから Beancount の元帳を生成します
- 家事関連費の按分について、**按分率そのものではなく「その率をどう出したか」**を
  仕訳のメタデータとして保全します
- 事業所得・給与所得・非課税収入を勘定科目の名前空間で分離し、
  決算書に混ざらないことを機械的に検査します

抽出は非決定的（モデルが読む）ですが、**集計は決定的**です。
同じ入力からは常に同じ元帳が出ます。

## 設計方針

| | |
|---|---|
| 原本を捨てない | 抽出はやり直せる。モデルが良くなったら再実行するだけ |
| 推測で埋めない | 読めない値は `null` + `needs_review`。数字を捏造しない |
| 金額・税務の判断を自動確定しない | 候補を出すところまで。決めるのは人間 |
| 税率・閾値を同梱しない | `templates/tax/` の値はすべて `null`。利用者が確認して設定する |

## データはこのリポジトリに入りません

本リポジトリは**アプリケーションのみ**を持ちます。
実際の帳簿・証憑・設定値は、利用者それぞれの別リポジトリに置きます。
